## T-705 — revision after a draft (one free, then charged)
Price rule (Vikram, 30 Oct): every draft includes one free revision; each further revision costs the same Ink as the original draft's quote; a failed revision is not charged; the free revision runs under the original quote's cost cap (Ink quoted × ₹9), never 0.

- Route: `POST /documents/:id/revise` `{note: 10–2000 chars}` → SSE identical to `/generate-from-brief`. Preconditions: document belongs to the user, has a delivered attempt, stored brief present (`Document.brief`); an in-flight attempt on the run → 409 `run_in_progress`; more than 10 revisions on one draft → 429 `revision_limit`.
- Run: same `runId`, next `runSequence`, `runType: 'revision'` (Generation `RUN_TYPES` already has it). `resolveRun` gets a revise branch that allows a new attempt after a completed one.
- Price: `Document.revisions = {count, freeUsed}`. count 0 → `inkQuoted 0`, cost cap = original initial attempt's `inkQuoted × 900` paise; count ≥ 1 → `inkQuoted` = the original initial attempt's `inkQuoted`. Hold/settle through the existing `holdInk`/`settleInk` plumbing; ledger reason `regenerate` (already accepted by `deductInk`); history line is an Ajay string.
- Drafter input: stored brief + ledger facts as for generate, plus `revision: {previousDraft, note}` where `previousDraft = finalContent ?? generatedContent` (the user's manual edits are the starting point). `streamGenerateFromBrief` takes an optional `revision` and appends one instruction block to the drafter prompt (text signed by Ajay; condition: the revision may not add facts not in the brief, ledger or note). Verify/repair and the T-611 gates run unchanged.
- Storage: the document's `version` increments; the previous content is kept in `previousVersions[]` (sealed, capped at 5, erased with the document); `finalContent` cleared after a successful revision (the new draft is the current text).
- Web: "Revise" on the document page → dialog with a note textarea, one line: first revision free / costs N Ink (Ajay strings), Confirm; the stream renders into the editor like generation; on `done` the document reloads. Error/cost-cap events reuse the existing handling.
- Legal: `ai.service.ts` is a legal-content path; Ajay signs the instruction block text and checks the diff at merge SHA.
